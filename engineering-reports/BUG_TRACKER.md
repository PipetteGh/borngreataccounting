# BUG TRACKER (`BorngreatAccounting`)

| ID | Module | Severity | Priority | Summary & Root Cause | Resolution & Files | Status |
|---|---|---|---|---|---|---|
| `BUG-001` | `Auth` / Windows Runtime | Critical | P0 | Native `bcrypt` addon failed to load on clean Windows machines (`502 Bad Gateway` on `/api/auth/signup`). | Replaced `bcrypt` with pure-JS `bcryptjs` in `packages/server/src/modules/Auth/Auth.utils.ts` and `packages/server/src/models/SystemUser.ts`. | **Closed (Verified)** |
| `BUG-002` | `Subscription` / Onboarding | Critical | P0 | Fresh system DB had empty `plans` table (`PLAN_NOT_FOUND` during signup). | Auto-seed `'free'` plan in `NewSubscription.service.ts` and run `system:seed:latest` in `scripts/windows-runtime.ps1`. | **Closed (Verified)** |
| `BUG-003` | `Windows Runtime` / MariaDB | High | P1 | Port `3306` conflict when XAMPP/MySQL is installed on host PC. | Added automatic fallback to port `3307` and `.env` synchronization in `scripts/windows-runtime.ps1`. | **Closed (Verified)** |
| `BUG-004` | `Setup` / `SMTP` | High | P1 | Onboarding jumped past `/setup/smtp` after DB build; saving SMTP settings returned `401 Unauthorized`. | Set `setOrganizationSetupCompleted(true)` before `refetch()` in `SetupInitializingForm.tsx`; added Bearer token & `organization-id` headers in `SmtpSettingsForm.tsx`. | **Closed (Verified)** |
| `BUG-005` | `POS` (`POSPage.tsx`) | High | P1 | `Complete Sale` button clipped in non-fullscreen mode; thermal receipt modal hidden in fullscreen mode; no 30s auto-close. | Dynamic viewport height calculation, sticky action footer, `portalContainer={isFullscreen && rootRef.current ? rootRef.current : undefined}`, and 30s auto-close countdown. | **Closed (Verified)** |
| `BUG-006` | `Automation` (`AutomationPage.tsx`) | High | P1 | Commands like `"update gari product with 20 quantity"` only updated 1 product and missed natural phrasing. | Token-based keyword extraction matching all matching items (`page_size=2000`) and concurrent 10-item batch execution. | **Closed (Verified)** |
| `BUG-007` | `Homepage` (`HomepageInsights.tsx`) | Critical | P0 | Docker deployment showed `"Sorry about that! Something went wrong"` when `salesByItems` returned a non-array object (`rawItems.map is not a function`). | Added strict `Array.isArray(...)` guards, `useCurrentOrganizationBaseCurrency()`, and `InsightsErrorBoundary`. | **Closed (Verified)** |
| `BUG-008` | `Charts` (`extractReportChartData.ts`) | High | P1 | Dashboard & report charts read `AGGREGATE` header rows instead of `TOTAL` rows (`INCOME`, `EXPENSES`, `NET_INCOME`, `ASSETS`, `LIABILITY`, `EQUITY`). | Matched exact server schema node IDs prioritizing `rowTypes.includes('TOTAL')` and resolved `total` column index from `table.columns`. | **Closed (Verified)** |
| `BUG-009` | `SMS` (`SmsIntegrationSettings.service.ts`) | Medium | P2 | If `sms_provider` setting was not explicitly saved, `getCredentials()` only checked Twilio even when Hubtel or SMSOnlineGH credentials were configured. | Added automatic fallback resolution across `resolveTwilio() \|\| resolveHubtel() \|\| resolveSmsOnlineGh()` + unit test in `SmsService.spec.ts`. | **Closed (Verified)** |
| `BUG-010` | `PaymentServices` (`PaymentGateways.controller.ts` & `.service.ts`) | High | P1 | External payment webhooks (`POST /api/payment-services/gateways/webhooks/:provider/:organizationId`) carried `:organizationId` in the URL path without setting `cls.set('organizationId', organizationId)`, leaving tenant DB context unset during webhook lookup. | Extracted `@Param('organizationId')` in `PaymentGatewaysController.handleWebhook` and propagated it into `cls.set('organizationId', organizationId)` inside `PaymentGatewaysService.verifyWebhook`. | **Closed (Verified)** |
| `BUG-011` | `PaymentServices` (`PaymentGateways.service.ts`) | Medium | P2 | Paystack HMAC-SHA512 webhook verification only hashed `JSON.stringify(body)` after `SerializeInterceptor` converted keys to camelCase, and did not accept raw payload buffers or capitalized header keys (`X-Paystack-Signature`, `Verif-Hash`). | Added rawBody + JSON HMAC-SHA512 verification and case-insensitive header lookup in `verifyWebhook`. | **Closed (Verified)** |
| `BUG-012` | `PaymentServices` (`PaymentGateways.service.ts`) | Medium | P2 | Paystack, Flutterwave, and Hubtel gateways did not fall back to `.env` test/default credentials (`PAYSTACK_*`, `FLUTTERWAVE_*`, `HUBTEL_*`) when DB row options were empty. | Added `getEffectiveOptions()` `.env` fallback in `PaymentGatewaysService` and 5 unit tests in `PaymentGateways.service.spec.ts`. | **Closed (Verified)** |
