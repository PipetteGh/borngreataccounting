# BorngreatAccounting Brand Assets

This directory contains the original editable vector assets and brand guidelines for **BorngreatAccounting** (`BtAccounting`).

## Product Identity
- **Product Name**: BorngreatAccounting
- **Short Name**: BtAccounting
- **Tagline**: Your Accounting. Your Servers. Your Control.
- **Publisher / Developer**: Peter Borngreat-Mensah (Borngreat / `soluotech`)

## Color Palette
| Role | Hex | Usage |
|---|---|---|
| Primary Brand Blue | `#004dd0` / `#0045ba` | Primary logotype, navigation accents, primary CTAs |
| Secondary / Growth Blue | `#2d95fd` / `#1968f0` | Rising ledger mark, secondary wordmark highlight, active states |
| Dark Surface | `#11161d` / `#1c2127` | Dark mode background & enterprise sidebar |
| Light Surface | `#ffffff` / `#f7f8fa` | Light mode background, cards, and report sheets |

## Editable Source Assets
- `borngreataccounting-logo.svg`: Full horizontal vector logo (mark + `BorngreatAccounting` wordmark).
- `borngreataccounting-mark.svg`: Standalone compact vector icon mark (`Bt` ledger & rising trend arrow).
